## 📌 Overview
Himalayan Shine Auto Care is an all-in-one web platform built specifically for the rugged terrain of Himachal Pradesh (Kullu, Manali, Kasol, Naggar, Solang, Jibhi). It provides on-demand doorstep washing, snow & sludge pressure cleaning, ceramic shine, and verified mountain valet pickup & drop services.

## ✨ Key Features
- **Terrain-Aware Dynamic Pricing**: Intelligent calculation covering mountain handling, incline logistics, and local valley zones.
- **Doorstep Mountain Valet**: Dedicated pickup & return service with a live order progression tracker.
- **Multi-Vehicle Support**: Tailored packages for Hatchbacks/Sedans, Mid-SUVs, 4x4 Mountain Beasts (Thar, Fortuner, Gurkha), and Adventure Tourer Bikes.
- **Advance Token System**: Transparent receipts offering standard full payments or flexible 20% advance booking deposits.
- **Multi-Channel Dispatch**: 1-click automated routing to WhatsApp (+91 8219528459) and official business email (`trippyworld21@gmail.com`).
- **Partner & Driver Tie-Up Portal**: Onboarding engine for local washing stations and mountain valet drivers across Himachal.
- **Booking History**: Local storage persistence to view and manage past bookings without a database setup.

## 🛠️ Tech Stack
- **HTML5 & Vanilla JavaScript**: Lightweight, ultra-fast load times on 4G mountain networks.
- **Tailwind CSS**: Modern, responsive UI with glassmorphic cards and polished dark-mode accents.
- **FontAwesome & Lucide Icons**: Intuitive mountain and automotive iconography.
